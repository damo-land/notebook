# notebook

Spotlight-style personal note capture + knowledge vault. Tauri v2 (Rust) + React/TypeScript (Vite).

## Dev

Run the app: `npm run tauri dev`

Other commands:

- `npm install` — install dependencies
- `npm run typecheck` — TypeScript typecheck
- `npm run build` — frontend build
- `cargo check` (inside `src-tauri/`) — check the Rust shell
