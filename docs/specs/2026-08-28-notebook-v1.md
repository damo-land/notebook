# Notebook v1 — Spotlight-style Capture + Knowledge Vault

Status: done
Source: Notes have no afterlife — captures die scattered (cogito, email-to-self, whatsapp) and never become queryable knowledge; existing apps fail on launch friction and feature overwhelm.

## Goal

Resident macOS overlay (hotkey → type → enter → gone) writing to a local
markdown vault (SQLite-indexed), with tasks view, alerts, search, background
LLM enrichment of knowledge notes, MCP access for Claude Code, and a thin
chat mode — daily-drivable v1 to dogfood.

## Non-goals

Mobile app, cloud sync, neo4j, cogito bridge, obsidian plugin, windows/linux
builds, temp-note category, manual "extraction mode", drag-drop ordering,
holo-style chat persona (fast-follow after v1).

## Riskiest assumption

Behavioral, not technical: the vault becomes a write-only graveyard unless
retrieval (search/chat/Claude) becomes a habit. Only dogfooding answers it.
