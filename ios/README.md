# stash for iPhone

A SwiftUI companion to the Mac app: Tasks, Notes and Knowledge sections,
tick off tasks, capture on the go, and chat with your notes using Apple's
on-device model (iOS 26+, iPhone 15 Pro or newer, Apple Intelligence on —
works offline). It reads and writes the **same vault
folder** as the Mac app, in the same file format, synced by iCloud Drive. No
server, no account. Works offline once the notes have downloaded.

A home-screen widget (small / medium / large) shows open tasks — due first,
or newest first, optionally one category (long-press → Edit Widget). Tap the
tasks to open the list, tap + to add a task. It shows tasks as of the last
time the app ran; iOS also runs a background refresh now and then.

Enrichment stays on the Mac — a `knowledge` note captured on the phone is
enriched when the Mac app sees it arrive. Notes refresh live while the app is
open (folder watcher, plus a 15s check for in-place edits).

## One-time setup

1. **Move the vault into iCloud Drive (Mac).** In Finder, create
   `iCloud Drive/Stash` and copy the contents of your current vault
   (`~/Notebook`) into it. Keep the old folder until you've checked
   everything works.
2. **Point the Mac app at it.** Tray icon → Settings… → vault location →
   `~/Library/Mobile Documents/com~apple~CloudDocs/Stash` (it shows up as
   `iCloud Drive/Stash` in Finder). The app reindexes immediately.
3. **Keep it downloaded on the Mac.** Right-click `iCloud Drive/Stash` in
   Finder → **Keep Downloaded**. Without this, macOS can evict notes to save
   space and the Mac app won't see them.
4. **Install on the iPhone** (below), open it, tap **Choose folder**, and pick
   `iCloud Drive/Stash`.

## Build and install

Requires Xcode 16+ and [XcodeGen](https://github.com/yonaskolb/XcodeGen)
(`brew install xcodegen`). The Xcode project is generated from
`project.yml` and is not committed.

```sh
cd ios
xcodegen            # writes Stash.xcodeproj
open Stash.xcodeproj
```

Plug the iPhone in (or pair it over Wi-Fi), select it as the run
destination, and press Run. The app and widget share an App Group
(`group.land.damo.stash`); if the first device build complains about it,
open the Stash target → Signing & Capabilities once so Xcode registers the
group for your team, then Run again. Signing is automatic with team `23Q8MBM5MM`; the
first run on a new phone asks you to trust the developer under Settings →
General → VPN & Device Management. Developer Mode must be on (Settings →
Privacy & Security → Developer Mode).

For TestFlight instead: Product → Archive → Distribute App → TestFlight.

## Develop

```sh
cd ios/StashCore && swift test          # format + list logic, runs on the Mac
STASH_VAULT_DIR=~/Notebook swift test   # also round-trips every real note
npx tsx scripts/ios-format-fixtures.ts  # (repo root) regenerate golden files
```

`StashCore` is a byte-for-byte port of `src/lib/vault` (frontmatter, note ids,
create/update) plus `src/lib/task-list.ts`. Its golden tests are generated by
running the TS library itself, so any change to the TS vault format must be
followed by regenerating `golden.json` and making `swift test` pass.

Simulator without iCloud: launch with a seeded throwaway vault —

```sh
xcrun simctl launch booted land.damo.stash.ios -sampleVault -screen notes
```

(`-screen`: `tasks`, `notes`, `knowledge`, `detail`, `edit`, `taskdetail`,
`undo`, `capture`, `capture-knowledge`, `settings`, `chat`, `onboarding`,
`widgets` — the last renders the widget's three sizes; Debug builds only.
`-openURL stash://new?kind=task` routes as a widget tap would.)

Chat can't run in the simulator on a Mac older than macOS 26. `-fakeChat`
swaps in a stand-in that answers with the same tool output the real model
sees; `-chatPrompt "…"` sends a first message:

```sh
xcrun simctl launch booted land.damo.stash.ios -sampleVault -fakeChat -screen chat -chatPrompt "What's due this week?"
```

Simulator against the real vault on this Mac (reads and writes live notes;
remembered until you choose a folder in Settings):

```sh
xcrun simctl launch booted land.damo.stash.ios -vaultPath "$HOME/Library/Mobile Documents/com~apple~CloudDocs/Stash"
```

## Layout

| Path | What |
|---|---|
| `project.yml` | XcodeGen spec (bundle id `land.damo.stash.ios`, iOS 17+) |
| `StashCore/` | Swift package, no UI: note format, ids, task sort/filter, search, link prep, file I/O |
| `StashCore/…/VaultFiles.swift` | iCloud-aware file I/O: placeholders, downloads, coordinated atomic writes |
| `Stash/VaultStore.swift` | App state, folder bookmark, optimistic writes |
| `Stash/Views/` | Tasks, Notes/Knowledge, note detail/editor, capture, settings, chat |
| `Stash/Chat/` | Chat model; Apple Foundation Models engine + tools; debug fake engine |
| `StashWidget/` | Widget extension: timeline provider, widget definition |
| `Shared/` | Compiled into app and widget: palette, App Group, widget views + intents |
